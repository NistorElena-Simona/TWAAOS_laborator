Despre Proiect

Această aplicație reprezintă un sistem modern și robust pentru gestionarea sarcinilor zilnice. A fost concepută ca un proiect complet care îmbină viteza extraordinară a unui backend Python cu flexibilitatea și frumusețea unei interfețe responsive.

Utilizatorii se pot înregistra securizat, se pot conecta cu datele lor, pot adăuga și edita sarcini în timp real, le pot filtra local în mod instantaneu, le pot marca drept finalizate cu micro-animații elegante și le pot șterge atunci când nu mai sunt necesare.

Caracteristici Cheie
  • Înregistrare & Logare securizată
  • Management complet al sarcinilor (CRUD)
  • Căutare și filtrare locală ultra-rapidă
  • Design Glassmorphic adaptiv pe orice dispozitiv

Arhitectura Tehnologică

FastAPI

Un framework web modern pentru Python, renumit pentru performanța extrem de ridicată și documentarea automată.

Bootstrap 5

Cea mai populară bibliotecă CSS pentru crearea de interfețe responsive, curate, mobile-friendly și extrem de elegante.

JWT Auth

Autentificare securizată prin JSON Web Tokens transmise criptat, asigurând protecția totală a datelor utilizatorului.
